## 📐 参数量计算详解

### WRN-28-10 (当前)

```
n_blocks = (28 - 4) // 6 = 4
n_channels = [16, 160, 320, 640]

Layer 1 (stride=1): 4 blocks × (16→160, 160→160)
Layer 2 (stride=2): 4 blocks × (160→320, 320→320)
Layer 3 (stride=2): 4 blocks × (320→640, 640→640)

每个block: 2个3×3卷积 + BN + shortcut

总参数: ~36.5M
```

### WRN-28-12 (增加宽度)

```
n_blocks = 4 (相同)
n_channels = [16, 192, 384, 768]

Layer 1: 4 blocks × (16→192, 192→192)
Layer 2: 4 blocks × (192→384, 384→384)
Layer 3: 4 blocks × (384→768, 768→768)

参数增长主要在每层的channel数:
- 160 → 192 (+20%)
- 320 → 384 (+20%)
- 640 → 768 (+20%)

但由于卷积参数 ∝ (channels)², 实际参数增长 ~(1.2)² ≈ 1.44倍

总参数: ~52.8M (+44%)
```

### WRN-40-10 (增加深度)

```
n_blocks = (40 - 4) // 6 = 6
n_channels = [16, 160, 320, 640] (相同)

Layer 1: 6 blocks × (16→160, 160→160)
Layer 2: 6 blocks × (160→320, 320→320)
Layer 3: 6 blocks × (320→640, 640→640)

每层block数从4增加到6 (+50%)

总参数: ~55.8M (+53%)
```

## 💾 GPU内存需求分析

### 内存组成

```
总GPU内存 = 模型参数 + 优化器状态 + 激活值 + 梯度

详细计算 (以WRN-28-10为例):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 模型参数: 36.5M × 4 bytes (FP32) = 146MB

2. 优化器状态 (AdamW):
   - momentum: 36.5M × 4 bytes = 146MB
   - variance: 36.5M × 4 bytes = 146MB
   - 小计: 292MB

3. 激活值 (batch_size=128):
   - Layer1 (4 blocks, 32×32 feature maps, 160 channels): ~100MB
   - Layer2 (4 blocks, 16×16 feature maps, 320 channels): ~50MB
   - Layer3 (4 blocks, 8×8 feature maps, 640 channels): ~25MB
   - 小计: ~175MB

4. 梯度: 36.5M × 4 bytes = 146MB

5. Mixed Precision (AMP) overhead: ~200MB

6. PyTorch缓存 & 其他: ~500MB

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总计: ~1.6GB (实际训练中观察到~4GB)
```

### 不同模型的内存估算

| 模型 | 参数量 | 基础内存 | 激活值内存 | 总内存估算 | 是否可行 (单卡16GB) |
|------|--------|---------|-----------|-----------|---------------------|
| WRN-28-10 | 36.5M | 730MB | 175MB | ~4GB | ✅ 绰绰有余 |
| WRN-28-12 | 52.8M | 1056MB | 252MB | ~5.5GB | ✅ 可行 |
| WRN-40-10 | 55.8M | 1116MB | 263MB | ~6GB | ✅ 可行 |
| WRN-40-12 | 80.3M | 1606MB | 378MB | ~8GB | ✅ 可行 (但较紧) |

**结论**: 所有候选模型都可以在单卡16GB GPU上训练（batch_size=128）

  • 参数 / 样本比: 52.8M / 40K = 1320 (+45%)
  • 预期: Train Acc ~73%, Val Acc ~80-81%

WRN-40-10 (55.8M):
  • 参数 / 样本比: 55.8M / 40K = 1395 (+53%)

## ⚠️ 潜在风险与缓解策略

### 风险1: 过拟合

**症状**: Train Acc >> Val Acc, Val F1在早期就不再提升

**缓解策略**:

```bash
# 增加dropout
--dropout 0.25  # (当前0.2)

# 或增加drop_path
--drop_path_rate 0.05  # (当前0.0)

# 或增加augmentation强度
--mixup_alpha 0.3 --cutmix_alpha 0.7
```

### 风险2: 训练不稳定

**症状**: Loss震荡，Val F1波动大

**缓解策略**:

```bash
# 降低学习率
--lr 0.0008  # (当前0.001)

# 或增加warmup
--warmup_epochs 15  # (当前10)

# 或使用gradient clipping
--max_grad_norm 0.5  # (当前1.0)
```

### 风险3: 内存不足

**症状**: CUDA out of memory

**缓解策略**:

```bash
# 降低batch_size
--batch_size 96  # (当前128)

# 注意: 降低batch_size后可能需要调整学习率
--lr 0.00075  # (96/128 * 0.001)
```
