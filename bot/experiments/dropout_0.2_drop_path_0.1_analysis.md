# Dropout 0.2 + Drop_path 0.1 实验结果分析

**实验时间**: 2025-10-24  
**分支**: resnet-best-practice  
**配置**: `--model wide_resnet28_10 --dropout 0.2 --drop_path_rate 0.1`  
**最终分数**: F1 = **0.81** (测试集)

---

## 📊 实验背景

### 前序实验对比

| 配置 | Overall F1 | Detail Classes | Local Classes | 备注 |
|------|-----------|----------------|---------------|------|
| **dropout 0.3** (baseline) | **0.82** | ~0.610 | ~0.810 | Phase-1 最佳 |

### 实验目标

验证 **dropout 0.2** 是否是 Detail classes 和 Local classes 的最优平衡点。

## 🎯 关键结论

### 1. **Dropout 0.2 ≈ Dropout 0.15 (几乎无差异)**

```
Overall F1:      0.81 = 0.81
Detail classes:  0.666 ≈ 0.664 (+0.002)
Local classes:   0.763 ≈ 0.760 (+0.003)
低性能类别:      6 = 6
```

**结论**: 0.15 到 0.2 的变化在**误差范围内**，说明这个区间是"平台期"。

---

### 2. **Dropout 0.2 不是平衡点**

**理由**:

1. ❌ 与 baseline (0.3) 仍有 -0.01 差距
2. ❌ Detail classes 提升饱和 (+0.056 vs baseline)
3. ❌ Local classes 持续下降 (-0.047 vs baseline)
4. ❌ 继续降低 dropout 无法突破

**真实情况**: Dropout 已经不是主要瓶颈！

---

### 3. **Dropout 调整的边际效应递减**

```
Dropout 变化:    0.3  →  0.2  →  0.15
模型容量:        70%  →  80%  →  85%
Detail 提升:     0%   → +0.3% → +0.3%  (饱和)
Local 下降:      0%   → -4.7% → -5.0%  (持续)
Overall:         82%  →  81%  →  81%   (下降)
```

**规律**:

- Detail classes 的提升在 dropout 0.2 时已经**饱和**
- 继续降低 dropout 只会损害 Local classes
- 说明瓶颈在**其他地方**！

## 🔬 瓶颈诊断

### 瓶颈 1: **Drop_path_rate = 0.1 过高** ⚠️⚠️⚠️

**当前配置**:

```python
dropout: 0.2 (已优化)
drop_path_rate: 0.1 (未变)
```

**影响分析**:

- WRN-28-10 共 28 层
- 每个 residual block 有 10% 概率被跳过
- 在 forward 时随机丢弃 ~3 层
- 梯度流不稳定，影响深层特征学习

**假设**: 降低 drop_path_rate 可能释放模型容量！

---

### 瓶颈 2: **Mixup/CutMix 对 Detail classes 破坏过大** ⚠️⚠️

**当前增强**:

```python
RandAugment: N=2, M=9 (中等强度)
Mixup: alpha=0.4 (中等混合)
CutMix: alpha=1.0 (强烈切割)
```

**对 Detail classes 的影响**:

- **boy/girl/man/woman**: 面部特征被 Mixup 混合 → 更难识别
- **mouse/shrew**: 小动物被 CutMix 切割 → 丢失完整轮廓

**证据**: 之前禁用 Mixup 的 dual-loader 实验失败，但原因是**类别不平衡**，不是策略本身无效。

---

### 瓶颈 3: **32×32 分辨率的物理限制** ⚠️

**人类类别的困境**:

```
原始 CIFAR-100 图片: 32×32×3
面部区域: ~20×20 像素
眼睛: ~3×3 像素
鼻子: ~2×2 像素
嘴巴: ~3×2 像素

信息不足以区分:
- boy vs girl
- man vs woman
- baby vs child
```

**结论**: 这是**架构无关**的硬限制，除非：

1. 使用超分辨率增强 (需要预训练，不可行)
2. 使用更强的注意力机制 (SE-Net 尝试过，效果不佳)
3. 使用 Ensemble (已尝试，0.82 → 0.82)

## 🎯 核心发现总结

1. ✅ **Dropout 0.2 = Dropout 0.15** (无差异)
2. ✅ **Dropout 优化已到瓶颈** (继续调整无效)
3. ✅ **Drop_path_rate 是下一个优化点** (当前 0.1 可能过高)
4. ✅ **Detail classes 的问题是多因素的** (分辨率 + 增强 + 架构)
5. ✅ **需要新的优化方向** (不能只靠 dropout)
