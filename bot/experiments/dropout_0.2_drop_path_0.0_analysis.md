```

```
drop_path 0.1:

## 🎓 **关键学习点**

### **1. Drop_path 的适用场景**

```
适合 Drop_path 的网络:
✅ 超深网络 (100+ 层)
  - ResNet-110, ResNet-152
  
不太需要 Drop_path:
⚠️ 中等深度网络 (20-50 层)
  - WideResNet-28 ← 我们的模型

WRN-28 的特点:
- 28 层 (不算太深)
- 但宽度很大 (10×)
- 参数量大 (36.5M)
- 已有强大表达能力

结论:
WRN-28 不需要强 Drop_path 正则化
drop_path 0.1 已经是过度正则化
```

---

### **2. 正则化的叠加效应**

```
当前正则化堆栈:
1. Dropout: 0.2 (神经元级)
2. Drop_path: 0.0 (层级) ← 移除
3. RandAugment (数据级)
4. Mixup/CutMix (数据级)

发现:
- Drop_path 0.1 + Dropout 0.2 = 过度正则化
- 移除 Drop_path 后效果更好
- 说明数据增强已经提供足够正则化

教训:
正则化不是越多越好
需要根据模型和数据调整
```

---

### **3. Detail Classes 的特殊性**

```
Detail classes (boy/girl/man/woman) 特点:
- 需要细微的特征区分 (面部)
- 对模型容量敏感
- 对梯度流稳定性敏感
- 受分辨率限制 (32×32)

优化策略:
✅ 提高模型容量 (降低 drop_path)
✅ 稳定梯度流 (drop_path 0.0)
✅ 引入 attention (SE-Net)
❌ 过强的 Mixup (破坏细节)

验证:
drop_path 0.0 → boy +0.12 ✅
说明策略正确
```
