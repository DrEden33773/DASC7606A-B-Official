## 🔍 自蒸馏失败原因

### 根本原因: 正则化叠加过度

**Exp #104b 配置已经很强**:

```
正则化技术 (已有):
1. Stochastic Depth
2. RandAugment  
3. Mixup/CutMix
4. Dropout
5. Weight Decay
6. EMA
7. Gradient Clipping
```

**自蒸馏 = 第 8 层正则化**:

- 中间分类器 = 多任务学习
- KL loss = 软标签约束

**结果**: 正则化过度 → 模型学习受限 → 性能下降

### 证据

**类别分布变化**:

- 困难类略好 (boy +0.08)
- 简单类略差 (lawn_mower -0.03)
- **整体下降** (-0.0163)

**解释**: 自蒸馏试图平衡所有类，但牺牲了整体性能
