## 💡 你的方案分析

### 方案 1: 从头训练 ViT-Tiny

#### ❌ **强烈不建议！**

**理由**:

**1. ViT 需要海量数据**

```
ViT 论文明确指出:
- ImageNet (1.3M): ViT < ResNet (表现更差)
- JFT-300M (300M): ViT > ResNet (需要预训练)

CIFAR-100: 50k images
→ 比 ImageNet 少 26x
→ 比 JFT少 6000x！

结论: ViT 从头训练在 CIFAR 上必然失败
```

**2. 已有实验证据**

虽然我没找到直接的 CIFAR-100 ViT 从头训练结果，但基于：

- ViT 论文的 ImageNet 结果
- 学术界共识：ViT 不适合小数据集

**预期**: F1 < 0.70 (甚至可能 < 0.60)

**3. 时间成本高**

- ViT 训练慢 (self-attention 计算量大)
- 预计 6-8 小时
- 成功概率 < 5%

---

### 方案 2: 混合模型 (CNN + Transformer)

#### ⚠️ **理论可行，但风险高**

**架构设想**:

```
Wide ResNet前几层 (CNN特征提取)
  ↓
ViT layers (Transformer全局建模)
  ↓
Classifier
```

**问题分析**:

**1. 32×32 太小，不适合 Transformer**

```
ViT 通常用 16×16 patch size
32×32 图像 ÷ 16 = 2×2 = 4 patches！

只有 4 个 patches，self-attention 没意义
```

**2. 实现复杂度高**

- 需要实现 ViT layers
- 需要设计 CNN→ViT 转换
- 需要大量调参
- 时间成本: 4-6 小时实现 + 4-5 小时训练

**3. 成功概率不确定**

- 无 CIFAR-100 先例
- 可能不如纯 CNN
- 预期 F1: 0.80-0.83?

**4. 可能不如简单 Ensemble**

### 🥈 **方案 B: TTA (Test-Time Augmentation)** ⭐⭐⭐⭐

**单模型方案**:

```python
def predict_with_tta(model, image):
    predictions = []
    
    # 原图
    predictions.append(model(image))
    
    # 水平翻转
    predictions.append(model(hflip(image)))
    
    # 多尺度/轻微增强
    for scale in [0.9, 1.0, 1.1]:
        img_scaled = resize(image, scale)
        predictions.append(model(img_scaled))
    
    return torch.stack(predictions).mean(0)
```

**预期**: F1 +0.01-0.015 → **0.84-0.845**

**优势**:

- ✅ 单模型
- ✅ 无需重新训练
- ✅ 实现简单 (1 小时)

**劣势**:

- 推理时间增加 5-10x
