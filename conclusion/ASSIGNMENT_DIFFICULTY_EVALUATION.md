# 📊 CIFAR-100 Assignment 难度评估

**客观评价**: 这个作业的难度设置**确实偏高**，甚至可以说**过于苛刻**

---

## 🔍 难度分析

### 约束条件的苛刻程度

#### 1. **禁止预训练** (极度严格)

**学术界现状**:

```
2024 年 SOTA 模型:
- 几乎全部依赖预训练
- ImageNet 预训练是标配
- 从头训练已经很少见
```

**文献证据**:

```
ViT 论文 (ICLR 2021):
"ViT 在 ImageNet 从头训练不如 ResNet"
"需要 JFT-300M 预训练才能超越"

ConvNeXt 论文 (CVPR 2022):
主要结果都基于 ImageNet-21k 预训练
```

**评价**: 禁止预训练相当于**倒退到 2016-2017 年的技术水平**

---

#### 2. **32×32 分辨率** (极度困难)

**人眼识别测试**:

```
让人类识别 32×32 的图像:
- 机械类 (motorcycle, truck): 90%+ 准确率
- 人类类 (boy, girl, man, woman): < 60% 准确率！

人眼都困难，要求模型达到 85%？
```

**分辨率对比**:

```
ImageNet: 224×224 (49× 信息量)
CIFAR-100: 32×32

信息丢失: 98%
```

**类比**:

- 让你通过一个模糊到几乎看不清的视频
- 分辨 100 种极度相似的物体
- 准确率要达到 85%

---

#### 3. **100 个细分类** (高复杂度)

**类别相似度极高**:

```
人类类: boy, girl, man, woman, baby (5 个)
- 32×32 下几乎无法区分
- 模型 F1 仅 0.57-0.65

小动物: beaver, otter, shrew, possum (4 个)
- 纹理细节完全丢失
- F1 约 0.58-0.65

相似度极高的类别占比: 20%+
```

**vs CIFAR-10**:

```
CIFAR-10: 10 个类别，差异明显
典型 F1: 0.90-0.95

CIFAR-100: 100 个类别，高度相似
我们的 F1: 0.82
```

---

#### 4. **满分标准: F1 ≥ 0.85** (过高)

**文献对比**:

```
Wide ResNet 论文 (BMVC 2016):
CIFAR-100 从头训练: ~81% acc

PyramidNet 论文 (CVPR 2017):
CIFAR-100 从头训练: ~83% acc

State-of-the-art (2024, 从头训练):
~83-84% acc

作业要求: 85% acc (F1 ≥ 0.85)
```

**评价**: **超过了当前学术界的水平！**

即使是 2017 年 CVPR 的 SOTA 也只有 83%，要求学生达到 85% 过于苛刻。
